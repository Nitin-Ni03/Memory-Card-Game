# Memory Card Game

An interactive memory matching game built with vanilla JavaScript, HTML, and CSS. Test your memory by finding matching pairs of cards!

## 🎮 How to Play

1. Click on cards to flip them and reveal hidden images or symbols
2. Try to find matching pairs of cards
3. Keep track of your moves and time
4. Match all pairs to complete the game
5. Challenge yourself to finish with the fewest moves possible

## ✨ Features

- **Interactive Gameplay** - Click-to-flip card mechanics with smooth animations
- **Scoring System** - Track your performance with move counter and timer
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dynamic DOM Manipulation** - Real-time updates using JavaScript event handling
- **Animated Transitions** - Smooth card flip and match animations for better UX
- **Reset Functionality** - Start a new game anytime
- **Progress Tracking** - Visual feedback for matched pairs and game completion

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and game structure
- **CSS3** - Responsive styling, animations, and transitions
- **JavaScript (Vanilla)** - Game logic, DOM manipulation, and event handling

## 🎯 Game Rules

- Each card hides a matching symbol or image
- Flip two cards at a time
- If they match, they stay revealed
- If they don't match, they flip back
- The game ends when all pairs are matched
- Try to complete the game with minimum moves and time!
